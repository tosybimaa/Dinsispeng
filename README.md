# Dinsispeng

## LVIT-10 — Sensor Level Air Induktif

Model 3D interaktif, perhitungan fisika, dan rig uji simulasi untuk sensor level air 0–10 cm berbasis pelampung dengan inti ferit (LVIT, *linear variable inductance transducer*).

- Halaman (Bahasa Indonesia): https://tosybimaa.github.io/dinsispeng/
- English version: https://tosybimaa.github.io/dinsispeng/en.html

Halaman statis tunggal tanpa proses build (`index.html`, `en.html`). Pustaka dimuat dari CDN: three.js 0.160.0 (jsDelivr), KaTeX 0.16.9 (cdnjs), dan Google Fonts.
